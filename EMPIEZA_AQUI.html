1. Extrae y copia el proyecto

  1. Extrae el ZIP completo.
  2. Abre tu repositorio en GitHub Desktop y elige Repository → Show in Explorer (o la opción equivalente para abrir la carpeta).
  3. Si ya funcionaba Google, guarda una copia de public/firebase-config.js.
  4. Copia aquí el contenido extraído y acepta combinar carpetas y reemplazar los archivos de la página.
  5. Vuelve a colocar tu configuración Firebase si la guardaste.

En la raíz deben verse package.json, netlify.toml, src y public. No subas el ZIP sin extraer ni pegues todos los archivos dentro de un único archivo.

2. Envía los cambios

En GitHub Desktop, revisa los archivos, escribe un resumen, pulsa Commit y después Push origin.

Si Netlify ya está conectado a esa rama y tiene los despliegues automáticos activos, construirá una nueva versión. Espera a que termine correctamente.
