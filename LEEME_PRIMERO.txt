HELLO ENGLISH · EDICIÓN 11

1. Extrae este ZIP completo.
2. En tu repositorio de GitHub, reemplaza el proyecto por el contenido extraído.
   En la raíz deben quedar package.json, package-lock.json, netlify.toml, src y public.
3. Si ya configuraste Google/Firebase, CONSERVA tu public/firebase-config.js.
   El archivo de esta entrega es una plantilla sin tus credenciales.
4. Netlify: comando de construcción npm run build; carpeta publicada public.
   Con un repositorio conectado y los despliegues automáticos activos, un commit
   en la rama configurada inicia un nuevo despliegue.
5. Espera a que el despliegue termine. Recarga la web y busca EDICIÓN 11 al pie.

No subas el ZIP como si fuera el código: sube su contenido extraído.
La carpeta public incluye también la versión compilada para despliegue manual.
No hace falta pagar una API de IA para estas actividades.
