Para actualizar GitHub

  1. Conserva tu configuración de public/firebase-config.js, si ya conectaste Google.
  2. Copia el contenido descomprimido en tu repositorio local con GitHub Desktop; después haz Commit y Push origin.
  3. Publica las reglas nuevas de firestore.rules en tu mismo proyecto Firebase.

Lee ACTUALIZAR_GITHUB.md para todos los pasos.
